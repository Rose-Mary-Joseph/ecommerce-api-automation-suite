## 📦 Project Overview

**Ecommerce API Automation Suite** is a REST API test framework built for validating the FakeStore Ecommerce APIs.  
It covers full CRUD scenarios for:

✔ Products  
✔ Users  
✔ Carts  

Along with:

✔ Schema validation  
✔ Role-based access testing  
✔ Authentication workflows  
✔ CI/CD execution with GitHub Actions  
✔ Allure reporting with GitHub Pages publishing
